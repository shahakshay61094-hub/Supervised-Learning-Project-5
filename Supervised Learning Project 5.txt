# 🎓 Smart Outcome Predictor using Ensemble Learning

## 📌 Project Overview

This project applies different Ensemble Learning techniques to predict:

- Course Completion Status (Classification)
- Final Student Score (Regression)

The project compares multiple ensemble algorithms and evaluates their performance using different classification and regression metrics.

---

# 📂 Dataset Information

**Dataset Name**

Smart_Outcome_Predictor_Dataset_5200.csv

### Dataset Contains

- Student Demographic Information
- Engagement Metrics
- Assessment Scores
- Course Completion Status
- Final Score

---

# 🎯 Project Objectives

- Predict course completion status.
- Predict final student score.
- Compare Bagging, Boosting, Voting and Stacking algorithms.
- Evaluate model performance.
- Recommend the best model for deployment.

# 💡 Key Findings

- Ensemble models improved prediction performance compared to a single Decision Tree.
- Boosting methods achieved better predictive accuracy by correcting previous model errors.
- Bagging reduced overfitting and increased model stability.
- Stacking combined multiple models to improve prediction quality.
- XGBoost and LightGBM provided strong performance on the dataset.
